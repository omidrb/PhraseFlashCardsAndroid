# Phrase Flash Cards v7.0

Visible app title: Phrase Flash Cards v7.0

Menu contains:
- Switch language
- Add new language
- Import CSV
- Export active language to CSV
- Dark mode
- Light mode

CSV format:
language,phrase,meaning_english,meaning_persian,usage,example,leitner_box

Important:
- Export includes ONLY the currently active language.
- Import adds rows as cards and creates missing language decks.
- Dark mode uses a black/dark-gray background and matching text/buttons.
- English and Persian meanings are separate card fields.
- Main workspace is compact; language dropdown is removed from the main screen.
