# Phrase Flash Cards v8.0

Major redesign:
- Home screen is now a 3-column Card Library.
- Each tile shows card number, phrase, Leitner box and Good/Hard/unreviewed state.
- Tap a tile: Show, Edit, Move to Leitner box, Delete.
- Long-press: multi-select cards; group Delete or Move Box.
- Search cards directly on the library screen.
- Add Card and Daily Practice remain at the bottom.
- The old full flashcard view is now used only in Daily Practice.
- Daily Practice keeps Show Answer, Good/Hard, Leitner progression, and next-day Hard priority.
- Menu retains language switching, language creation, CSV import/export, Leitner tools and dark/light mode.
- CSV import accepts both 2-column Phrase,Meaning and 4-column Phrase,English Meaning,Persian Meaning,Example.
- CSV export exports only the active language.
